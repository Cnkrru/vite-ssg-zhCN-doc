## 对比

### 当你需要以下情况时，请使用 [Vitepress](https://github.com/vuejs/vitepress)

- 零配置、开箱即用的 SSG
- 单一用途的文档站点
- 轻量（[No double payload](https://twitter.com/youyuxi/status/1274834280091389955)）

### 当你需要以下情况时，请使用vite-ssg
- 对构建过程和工具链有更多控制
- 灵活的插件系统
- 兼具多种用途的应用，并通过一些 SSG 来提升 SEO 和加载速度

缺点:
- double payload

See [Vitesse](https://github.com/antfu/vitesse).
